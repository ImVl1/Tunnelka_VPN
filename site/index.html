Подписки как есть

Работает с Marzban, Remnawave, 3x-ui и другими панелями. Показывает остаток трафика и срок, обновляет список серверов сам.

Раздельный туннель

Выберите, какие программы и сайты идут через VPN, а какие напрямую. Российские сайты можно сразу пустить мимо туннеля.

Без утечек

Kill switch блокирует интернет, если VPN отвалился. DNS и IPv6 не уходят мимо туннеля, локальные порты закрыты паролем.

Сам находит рабочий путь

Если сервер не отвечает, переключится на живой. Если провайдер ломает режим TUN, перейдёт на системный прокси.

Автовыбор сервера

Выбирает сервер с наименьшей задержкой и меняет его без разрыва соединения.

Тихо в трее

Запуск вместе с Windows и подключение при старте — по желанию, по умолчанию выключены.
