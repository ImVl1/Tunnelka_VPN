Защита

Пока VPN включён, брандмауэр Windows пропускает в интернет только трафик через VPN. Если ядро упадёт, программы не смогут выйти в сеть напрямую. Кнопка «Отключить» снимает блокировку.

На Android kill switch включается в системе: «Постоянная VPN» и «Блокировать соединения без VPN» для Tunnelka.
