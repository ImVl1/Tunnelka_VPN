Как подбирать замену

      
Если выбранный сервер перестал отвечать, Tunnelka проверяет серверы по шагам сверху вниз. На каждом шаге выбирается самый быстрый рабочий сервер; если на шаге не ответил ни один — переход к следующему. Порядок меняется стрелками, ненужный шаг можно выключить.
